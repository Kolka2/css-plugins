# Очередь заданий

| # | Задание | Плагины | Зависит от | Статус |
|---|---|---|---|---|
| 1 | `NADETHROW_TASK.md` | `nadethrow` | — | выполнено, ждёт проверки на сервере |
| 2 | `PRACTICE_TASK.md` | `nadepractice` | `nadethrow` (необязательно, но лучше после него) | готово к работе |

| 4 | `EXECUTES_TASK.md`, задание B | `botcontrol` | — (лучше после `nadepractice`) | черновик |

«Черновик» — перед запуском сверить с тем, что получилось в предыдущих заданиях (в каждом черновике есть раздел «Что сверить перед запуском»).

## Как запускать

Новая сессия Claude Code в корне репозитория, первое сообщение:

> Прочитай `CLAUDE.md`, `ARCHITECTURE.md` и `tasks/<ЗАДАНИЕ>.md`. Выполни задание.

Продолжить прерванное:

> Прочитай `CLAUDE.md` и `docs/<плагин>/PROGRESS.md`, продолжи со следующего шага.
