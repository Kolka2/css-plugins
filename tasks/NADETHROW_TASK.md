# Задание: плагин `nadethrow` — броски гранат с ЛКМ, ПКМ и ЛКМ+ПКМ в CS:S

Скопируй всё, что ниже линии, первым сообщением в новую сессию Claude Code. В репозиторий положи `ARCHITECTURE.md` и папку `templates/` из проекта «CS:S», а также `tools/` и `build.sh` из репозитория порта Retakes (компилятор SourcePawn 1.12 и include-файлы SourceMod 1.12).

---

Напиши SourceMod-плагин `nadethrow` для Counter-Strike: Source, который добавляет броски гранат разной силы, как в CS:GO: ЛКМ — сильный бросок, ЛКМ+ПКМ — средний, ПКМ — лёгкий бросок «снизу».

## Контекст

- Сервер: CS:S (обновление февраля 2025, 64-бит), Metamod:Source 1.12, SourceMod 1.12. Только CS:S.
- Все правила — в `ARCHITECTURE.md`. Прочитай его первым и следуй ему: слои, «один владелец», имена, обязательные квары, `userid` в таймерах, `CSS-VERIFY`, отладочный лог. За основу возьми `templates/example.sp` и `templates/include/example.inc`.
- Сборка: `./build.sh` (компилятор `tools/spcomp`, include-файлы в `tools/include`). Если `build.sh` рассчитан на другую структуру, поправь его.
- Сервера CS:S у тебя нет. Всё, что зависит от поведения движка, пиши защитно, помечай `// CSS-VERIFY: <что проверить>` и добавляй пункт в `TEST_CHECKLIST.md`. Не утверждай, что что-то «работает в игре».
- Без gamedata/DHooks и сторонних библиотек. Только sdktools, sdkhooks, cstrike.

## Место в архитектуре

- Слой: **сервис** (механика игры, нужная разным режимам: Retakes, 5×5, тренировка гранат `nadepractice`).
- Владеет: обработкой ПКМ, пока у игрока в руках граната; начальными скоростью и позицией снаряда для бросков с силой меньше 1.0.
- Ничего не знает о режимах. Использует только API SourceMod.
- `nadepractice` позже будет использовать `nadethrow` как необязательную зависимость (предпросмотр траектории с учётом силы, поле «сила броска» в лайнапе). Поэтому API должно быть стабильным и задокументированным.

## Поведение

### Сила броска

| Кнопки в момент броска | Сила |
|---|---|
| ЛКМ | 1.0 |
| ЛКМ + ПКМ | 0.5 |
| ПКМ | 0.0 |

- Пока игрок держит гранату с выдернутой чекой, сила определяется текущими зажатыми кнопками и может меняться (зажал вторую кнопку — сила изменилась).
- Бросок происходит, когда отпущены **обе** кнопки. Сила берётся из последнего тика, когда была зажата хотя бы одна.
- При силе 1.0 плагин **ничего не меняет** в снаряде: обычные броски и все привычные раскидки CS:S остаются точно такими же. Это главное требование.

### Ввод (`OnPlayerRunCmd`)

- Только если в руке `weapon_hegrenade`, `weapon_flashbang` или `weapon_smokegrenade`.
- Пока зажата ЛКМ или ПКМ, в команду передаётся `IN_ATTACK` (чтобы игра выдёргивала чеку и держала гранату как обычно), а `IN_ATTACK2` убирается. `CSS-VERIFY:` что ПКМ с гранатой в CS:S сама по себе ничего не делает и что подмена не ломает анимацию выдёргивания чеки.
- Запоминать на игрока: текущую силу, силу в момент броска, скорость игрока в момент броска.
- Сброс состояния: смена оружия, смерть, выход, смена карты.
- Боты не затрагиваются (обрабатывать только людей, если квар не говорит иначе).

### Поправка снаряда

- Ловить появление `hegrenade_projectile`, `flashbang_projectile`, `smokegrenade_projectile` (`OnEntityCreated` → `SDKHook_SpawnPost`), сопоставлять с владельцем (`m_hThrower` или `m_hOwnerEntity`, `CSS-VERIFY:`), брать силу броска владельца.
- Если сила < 1.0 — в следующем кадре (`RequestFrame`, передавая ссылку на сущность через `EntIndexToEntRef`) пересчитать:
  - **скорость:** масштабируется только «собственная» часть броска, а скорость игрока остаётся: `new = (v - playerVel) * k + playerVel`, где `k = minScale + (1 - minScale) * strength`. `CSS-VERIFY:` что в CS:S скорость игрока добавляется к броску целиком; если нет — подобрать и описать. Код броска CS:S ищи в Source SDK 2013 (`weapon_basecsgrenade` и связанное).
  - **позиция вылета:** опустить на `(1 - strength) * zOffset` юнитов по вертикали; проверить трассировкой, что новая точка не в стене, иначе оставить исходную.
  - применить через `TeleportEntity`.
- Константы `minScale` (по умолчанию 0.3) и `zOffset` (по умолчанию 12.0) — квары: это примерные значения из CS:GO, их будут подстраивать на сервере.
- `CSS-VERIFY:` что игра не перезаписывает скорость снаряда после первого кадра и что на клиенте нет заметного рывка гранаты.
- Таймер детонации не трогать.

### Подсказка (необязательно)

- Квар `sm_nadethrow_hint` (по умолчанию 0): пока игрок держит гранату с выдернутой чекой, показывать силу броска («Бросок: сильный / средний / лёгкий»).

## API (`scripting/include/nadethrow.inc`)

```
#define NADETHROW_LIBRARY "nadethrow"
#define NADETHROW_API_VERSION 1

// Включён ли плагин (sm_nadethrow_enabled).
native bool Nadethrow_IsEnabled();

// Текущая сила броска игрока (0.0–1.0), пока он держит гранату с выдернутой чекой; иначе -1.0.
native float Nadethrow_GetThrowStrength(int client);

// Параметры, по которым плагин пересчитывает бросок (для предпросмотра в других плагинах).
native float Nadethrow_GetMinScale();
native float Nadethrow_GetZOffset();

// Уведомление: граната брошена (после поправки снаряда, если она была).
forward void Nadethrow_OnGrenadeThrown(int client, int projectile, float strength);
```

Форвард вызывается и для бросков с силой 1.0. Плюс `SharedPlugin` и `__pl_nadethrow_SetNTVOptional`, как в шаблоне.

## Квары

| Квар | По умолчанию | Смысл |
|---|---|---|
| `sm_nadethrow_enabled` | 1 | включить механику |
| `sm_nadethrow_debug` | 0 | лог в `logs/nadethrow_debug.log`: сила, скорость до и после поправки, позиция вылета |
| `sm_nadethrow_version` | — | версия |
| `sm_nadethrow_min_scale` | 0.3 | доля скорости при силе 0.0 |
| `sm_nadethrow_z_offset` | 12.0 | насколько ниже вылетает граната при силе 0.0 |
| `sm_nadethrow_hint` | 0 | подсказка силы броска |
| `sm_nadethrow_bots` | 0 | обрабатывать ли ботов |

## Что должно быть в `TEST_CHECKLIST.md` (минимум)

- ЛКМ: бросок идентичен броску без плагина (сравнить точку падения с плагином и без, с одной позиции и углов, стоя и на бегу).
- ЛКМ+ПКМ и ПКМ: граната летит заметно слабее, на бегу скорость игрока сохраняется.
- Порядок нажатий: зажал ЛКМ → добавил ПКМ → отпустил обе; зажал ПКМ → добавил ЛКМ; отпустил кнопки по очереди.
- Анимация выдёргивания чеки при ПКМ нормальная.
- Рывка гранаты в начале полёта не видно.
- Смена оружия с выдернутой чекой, смерть с гранатой в руке — без ошибок в логе.
- Боты бросают как обычно.
- Все пункты `CSS-VERIFY`.
