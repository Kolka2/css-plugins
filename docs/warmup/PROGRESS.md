# warmup — ход работы

## Текущее состояние

- **Этап:** плагин перенесён из `Kolka2/css-retakes` (решение владельца 2026-11-16: общий сервис должен жить рядом с другими плагинами). Версия 1.1.0, собирается без предупреждений; на сервере проверена версия 1.0.0 в составе Retakes.
- **Сделано при переносе** (поведение не менялось, по решению владельца):
  - `warmup.inc`: константы `WARMUP_LIBRARY`, `WARMUP_API_VERSION` (1), натив `Warmup_GetApiVersion()`; остальной API прежний, плагины со старым include работают;
  - `warmup.sp`: шапка «Layer / Owns / Reads / Uses / API» по `ARCHITECTURE.md`, строка в лог при загрузке (`OnAllPluginsLoaded`), `#include <warmup>`, адрес репозитория в `myinfo`;
  - `docs/warmup/README.md` (ru + en), `TEST_CHECKLIST.md` (перенесён из css-retakes с отметками владельца), этот файл.
- **Не сделано намеренно** (решение владельца): префиксы глобальных переменных `g_h…` не переименованы в `g_cv…` / `g_fwd…`, как требует раздел 8 `ARCHITECTURE.md`; форварды остаются `Handle` + `CreateGlobalForward`, а не `GlobalForward`. Плагин проверен на сервере, косметические правки не стоят риска.
- **Следующий шаг:** владелец проверяет на сервере раздел «Версия 1.1.0» и неотмеченные пункты `TEST_CHECKLIST.md`. В css-retakes лежит копия `warmup.inc`: при изменении API обновлять её там тоже.
- **Открытые вопросы:** нет.

## История

История изменений плагина до переноса — в репозитории `Kolka2/css-retakes` (коммиты с `warmup` в описании, 11–14.11.2026). Решения того времени, которые стоит знать:

- разминку на старте карты запускает режим (`Warmup_Start`), поэтому `sm_warmup_autostart` по умолчанию `0`;
- `Warmup_End()` завершает разминку сразу, без `Warmup_OnEnding`;
- свободная смена T ↔ CT в разминке живёт в этом плагине (`CS_SwitchTeam` + респаун), владелец просил сохранить её при выносе разминки из Retakes;
- C4 убирается двумя путями (запрет подбора и ежесекундная проверка): по логам 14.11 нужны оба;
- после каждого hint-сообщения отсчёта гасится звук `UI/hint.wav`;
- `sm_warmup 0` — разминка без лимита времени (а не «закончить»), отсчёт идёт только при людях на сервере — оба поведения оставлены по решению владельца.
