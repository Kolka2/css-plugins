# warmup — что проверить на сервере

Перенесено из чеклиста css-retakes (разделы «Плагин разминки» и «Разминка: краевые случаи»). Отмеченные пункты подтверждены владельцем на сервере 14.11.2026 вместе с Retakes (версия 1.0.0). Пометок `CSS-VERIFY` в коде нет.

Отладочный лог: `sm_warmup_debug 1`, файл `addons/sourcemod/logs/warmup_debug.log`.

## Версия 1.1.0 (перенос в css-plugins)

- [ ] В логе SourceMod при загрузке строка `version 1.1.0, API 1` от `warmup.smx`.
- [ ] Retakes, собранный со старым `warmup.inc` (без `Warmup_GetApiVersion`), работает с новым `warmup.smx` как раньше.

## Загрузка

- [x] `sm plugins list` показывает «CS:S Warmup», в логе ошибок нет строк от `warmup.smx`; создан `cfg/sourcemod/warmup.cfg`.

## Бесконечный раунд и респаун

- [x] Раунд не заканчивается, когда одна команда целиком убита или вышло время; игра после этого не зависает. Таймер раунда на HUD стоит около 60:00.
- [x] Убитый появляется через `sm_warmup_respawn_time` секунд (1.5 и, например, 5).
- [x] Игрок, зашедший в команду посреди разминки, появляется через 1–2 с после выбора модели; пока меню модели открыто — не появляется (`m_iClass`).

## Деньги и покупка

- [ ] При появлении $16000; после покупки деньги сразу снова $16000 (`m_iAccount`). С `sm_warmup_infinite_money 0` деньги не меняются.
- [ ] В зоне закупки можно покупать и через несколько минут после начала разминки; `mp_buytime` в консоли показывает 1440.
- [ ] После разминки `mp_buytime` снова прежний. То же после смены карты посреди разминки и после `sm plugins unload warmup` посреди разминки.
- [x] `sm_warmup_buy_anywhere 1`: закупка открывается в любой точке карты (`m_bInBuyZone`); с `0` — только в зоне закупки.

## Бомба

- [x] C4 нет ни у кого и на земле; после рестарта раунда внутри разминки (Game Commencing) её тоже нет; то же в разминке, запущенной командой на пустом сервере и посреди живого раунда.
- [x] Разминка, запущенная в раунде с установленной бомбой: бомба исчезает, взрыва и конца раунда нет.

## Смена команды и отсчёт

- [x] Через меню команд (M) можно перейти из T в CT и обратно сколько угодно раз: игрок сразу появляется на спавне новой команды с её моделью.
- [x] Отсчёт виден внизу экрана и идёт без звукового сигнала каждую секунду (`UI/hint.wav`).

## Конец разминки

- [ ] `sm_warmup_time 25`, `sm_warmup_min_players 1`: без людей отсчёта нет; зашёл человек — отсчёт с 25; по окончании рестарт игры.
- [ ] `sm_warmup_min_players 2` и один человек: подсказка «ждём игроков (1/2)», отсчёт не идёт; зашёл второй — пошёл; один вышел — отсчёт сбросился.
- [ ] `sm_warmup 0` при `sm_warmup_min_players 2`: разминка без времени, заканчивается, как только на сервере два человека.
- [ ] `sm_warmup 0` при `sm_warmup_min_players 0`: разминка идёт, пока не выполнить `sm_warmup_end`.
- [ ] `sm_warmup_restart_delay 0`: игра после разминки не перезапускается (если режим, например Retakes, не перезапускает её сам).
- [ ] Без режима: `sm_warmup_autostart 1` — разминка начинается на каждой карте.

## Краевые случаи (с `sm_warmup_debug 1`)

- [x] Вся команда мертва: раунд не перезапускается, мёртвые возрождаются; в логе `round: end blocked, reason 7` или `reason 8`.
- [x] Обе команды мертвы одновременно — то же.
- [x] Команда опустела и снова наполнилась: в логе `teams: …`, раунд не перезапускается.
- [x] Последний человек вышел и зашёл: один рестарт («Game Commencing»), отсчёт начинается заново.
- [x] Время раунда: строк `end blocked, reason 11` нет — часы раунда продлеваются раньше, чем истекают.
- [x] Чужое значение квара: `mp_buytime 0.25` во время разминки — в логе `cvar: mp_buytime was set to 0.25 …`, купить по-прежнему можно, после разминки `mp_buytime` равен 0.25.
- [x] Вето режима (редактор Retakes): в логе один раз `another plugin keeps the warmup going`, разминка не кончается, пока режим не разрешит.
- [x] Смена карты посреди разминки: `warmup ended, reason 2`, `game restart: no`.
- [ ] `sm plugins unload warmup` посреди разминки: `reason 3`, `mp_buytime` возвращён.

## Вместе с Retakes

Проверяется по чеклисту css-retakes: старт разминки по `sm_retakes_warmuptime`, Retakes ничего не делает в разминке, первый ретейк после неё, `sm_retakes_warmup`, редактор во время разминки, выгрузка `warmup.smx` посреди разминки.

## Конфигурации сервера

- Retakes + warmup (основная).
- warmup без режима, `sm_warmup_autostart 1`.
