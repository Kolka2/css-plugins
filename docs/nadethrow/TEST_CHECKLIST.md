# nadethrow — что проверить на сервере

Ничего из этого не проверено: сервера CS:S в среде разработки нет.

Подготовка: `sm_nadethrow_debug 1`, `sv_cheats 1`. Показа траектории в CS:S нет, поэтому точку падения сравнивать по месту взрыва или дыма, бросая с одной позиции и углов (`setpos` / `setang`). Лог: `addons/sourcemod/logs/nadethrow_debug.log`.

## Главное требование: ЛКМ не меняется

- [ ] ЛКМ стоя: точка падения с плагином и с `sm_nadethrow_enabled 0` совпадает (одна позиция и углы, HE, флешка, дым).
- [ ] ЛКМ на бегу (вперёд, назад, вбок, в прыжке): то же.
- [ ] В debug-логе для бросков с ЛКМ: `strength 1.0, unchanged`.
- [ ] Привычные раскидки на картах работают как раньше.

## Средний и лёгкий бросок

- [ ] ЛКМ+ПКМ: граната летит заметно слабее, чем с ЛКМ; ПКМ — ещё слабее и вылетает ниже.
- [ ] ЛКМ+ПКМ и ПКМ на бегу: скорость игрока сохраняется (граната не «отстаёт» от бегущего игрока сильнее, чем при ЛКМ).
- [ ] ПКМ в упор к стене и глядя в пол: граната не проваливается в стену или пол (в логе `blocked, position kept`).
- [ ] Подобрать `sm_nadethrow_min_scale` и `sm_nadethrow_z_offset`, сравнив с CS:GO.

## Порядок нажатий

- [ ] Зажал ЛКМ → добавил ПКМ → отпустил обе «одновременно»: сила 0.5.
- [ ] Зажал ПКМ → добавил ЛКМ → отпустил обе: сила 0.5.
- [ ] Зажал обе → отпустил ПКМ → подержал ЛКМ дольше 0.1 с → отпустил: сила 1.0.
- [ ] Зажал обе → отпустил ЛКМ → подержал ПКМ дольше 0.1 с → отпустил: сила 0.0.
- [ ] Отпускание по очереди быстрее 0.1 с даёт 0.5; подобрать `sm_nadethrow_release_grace` (0 — строго по последнему тику, как в задании).
- [ ] Быстрый клик ПКМ (нажал и сразу отпустил): граната брошена с силой 0.0.
- [ ] Две флешки подряд разными кнопками: у каждой своя сила.

## Анимация и картинка

- [ ] Анимация выдёргивания чеки при ПКМ нормальная (от первого лица и со стороны).
- [ ] Рывка гранаты в начале полёта не видно — от первого лица, у наблюдателя и у другого игрока; проверить с пингом 50–100.
- [ ] Подсказка (`sm_nadethrow_hint 1`): текст появляется при выдернутой чеке, меняется при смене кнопок, не мигает, на русском клиенте — по-русски.

## Устойчивость

- [ ] Смена оружия с выдернутой чекой (ЛКМ, ПКМ, обе) — без ошибок в логе; следующий бросок с ЛКМ обычный.
- [ ] Смерть с гранатой в руке и выдернутой чекой — без ошибок в логе.
- [ ] Выход игрока с выдернутой чекой, смена карты во время удержания — без ошибок.
- [ ] ПКМ во время фризтайма и во время доставания гранаты: ничего не ломается, следующий бросок правильный.
- [ ] `sm_nadethrow_enabled 0` посреди удержания ПКМ: граната не «залипает» в руке навсегда (после отпускания и нажатия ЛКМ бросается как обычно).
- [ ] Поздняя загрузка плагина (`sm plugins load nadethrow` посреди раунда) — работает без смены карты.
- [ ] В логе ошибок SourceMod нет строк `m_bPinPulled not found`, `m_vecAbsVelocity not found`, `Neither m_hThrower nor m_hOwnerEntity found`.

## Боты

- [ ] `sm_nadethrow_bots 0`: боты бросают как обычно, в debug-логе их броски — `strength 1.0, unchanged`.
- [ ] `sm_nadethrow_bots 1`: боты бросают как обычно (сами ПКМ не нажимают).

## API

- [ ] `Nadethrow_OnGrenadeThrown` приходит для бросков с силой 1.0, 0.5, 0.0 и для ботов; `projectile` — валидная сущность.
- [ ] `Nadethrow_GetThrowStrength` возвращает -1.0 без выдернутой чеки и 1.0 / 0.5 / 0.0 при удержании.

## CSS-VERIFY (по коду `scripting/nadethrow.sp`)

- [ ] ПКМ с гранатой в CS:S сама по себе ничего не делает (без плагина).
- [ ] Подмена ПКМ на `IN_ATTACK` не ломает анимацию выдёргивания чеки.
- [ ] У гранат есть сетевое свойство `m_bPinPulled`, оно true с тика нажатия до тика отпускания (иначе сила не запоминается и все броски будут обычными — в логе `pin not pulled, no throw`).
- [ ] Текст по центру (`PrintCenterText`) держится дольше 1 с и не мешает.
- [ ] В момент `SpawnPost` владелец снаряда известен через `m_hOwnerEntity`; `m_hThrower` / `m_hOwnerEntity` вообще читаются у снарядов.
- [ ] Поправка происходит в том же тике: в debug-логе `via cmdpost`. Если везде `via frame` — работает запасной путь (следующий кадр), проверить рывок особенно внимательно.
- [ ] CS:S добавляет к броску скорость игрока целиком и берёт её в момент создания снаряда: в логе `vel - player vel` при ЛКМ не зависит от движения игрока (сравнить стоя и на бегу при одних углах).
- [ ] Игра не перезаписывает скорость снаряда после поправки (граната летит по новой траектории с первого кадра).
- [ ] У снарядов есть `m_vecInitialVelocity`; с ним у клиента нет рывка в первые кадры.
